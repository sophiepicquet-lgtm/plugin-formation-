# Plugins de formation — Un peigne pour un chauve

Plugins Claude utilisés par Sophie Picquet dans ses formations IA.

| Plugin | Public | Contenu | Auteur |
|---|---|---|---|
| [artisans-vst](artisans-vst) | Artisans du bâtiment | Préparation de devis, comptes rendus de visite, compte rendu technique interne, veille des appels d'offres, relance de paiement | Sophie Picquet |
| [linkedin-agent](linkedin-agent) | Indépendants, dirigeants, consultants | 11 compétences LinkedIn : posts, commentaires, réponses, profil, planning, messages, carrousels, audit, humaniseur | Jake Schincariol (licence MIT) |

## Télécharger

- **Artisans VST, prêt à installer** : [artisans-vst-v1.zip](artisans-vst-v1.zip)
- **LinkedIn Agent, prêt à installer** : [linkedin-agent-v1.1.zip](linkedin-agent-v1.1.zip)

L'installation est présentée pendant la formation.

## Règles communes (Artisans VST)

- Aucun prix, métrage, quantité définitive ou conformité n'est inventé.
- Toute information manquante est signalée « À confirmer ».
- Le chiffrage, le choix technique et le devis final restent sous la responsabilité de l'artisan.
