# Plugins de formation — Un peigne pour un chauve

Plugins Claude conçus par Sophie Picquet pour ses formations IA.

| Plugin | Public | Contenu |
|---|---|---|
| [artisans-vst](artisans-vst) | Artisans du bâtiment | Préparation de devis, comptes rendus de visite, compte rendu technique interne, veille des appels d'offres, relance de paiement |

## Télécharger

- **Plugin prêt à installer** : [artisans-vst-v1.zip](artisans-vst-v1.zip)

L'installation est présentée pendant la formation.

## Règles communes

- Aucun prix, métrage, quantité définitive ou conformité n'est inventé.
- Toute information manquante est signalée « À confirmer ».
- Le chiffrage, le choix technique et le devis final restent sous la responsabilité de l'artisan.
