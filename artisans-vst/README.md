# Artisans VST — assistants métier pour artisans du bâtiment

© Sophie Picquet — Un peigne pour un chauve. Plugin conçu pour la formation « IA pratique pour artisans du bâtiment ». Tous droits réservés.

Version 1.0.0

## Ce que contient le plugin

| Skill | À quoi il sert | Exemple de demande |
|---|---|---|
| Préparation de devis | Transformer des notes de visite en fiche de préparation au devis, sans aucun prix inventé | « Voici mes notes de visite chez M. Martin, prépare la fiche devis » |
| Compte rendu de visite client | Rédiger un compte rendu clair après une visite, avec un message de suivi pour le client | « Fais le compte rendu de ma visite de ce matin » |
| Compte rendu technique interne | Préparer une synthèse technique pour l'équipe et une base de pré-devis sans prix | « Fais le CR technique interne pour l'équipe » |
| Veille appels d'offres | Rechercher et classer les marchés publics accessibles à une TPE du bâtiment | « Lance la veille des appels d'offres de la semaine » |
| Relance de paiement | Rédiger une première relance douce et professionnelle | « Prépare une relance pour la facture 2026-112 » |

## Comment l'utiliser

- Écrivez normalement : Claude choisit le bon skill selon votre demande.
- Ou tapez **/** dans la zone de message et choisissez le skill dans la liste.

## Règles communes à tous les skills

- Aucun prix, métrage, quantité définitive ou conformité n'est inventé.
- Toute information manquante est signalée « À confirmer ».
- Le chiffrage, le choix technique et le devis final restent sous la responsabilité de l'artisan.
