# Modèle — Compte rendu technique interne

Version artisan / équipe : préparation du pré-devis sans chiffrage automatique.

Finalité : transformer des notes terrain souvent désordonnées en synthèse technique exploitable par l'artisan, son équipe ou son assistante. Ce modèle prépare le devis mais ne remplace pas le chiffrage dans l'outil métier.

## 1. Synthèse rapide de la visite
| Champ | Contenu attendu |
|---|---|
| Client / chantier | Nom client + adresse + type de bâtiment |
| Nature de la demande | Dépannage / rénovation / création / mise aux normes / extension |
| Niveau d'urgence | Faible / moyen / élevé + justification factuelle |
| Décision à prendre | Visite complémentaire / devis possible / informations manquantes / intervention impossible à ce stade |
| Qualité des données collectées | Suffisante / partielle / insuffisante pour devis |

## 2. Relevé par zone ou équipement
| Zone | Demande / constat | Informations utiles au devis | Manques à lever |
|---|---|---|---|
| Ex. tableau électrique | Remplacement demandé | Accès, puissance, protections visibles | Référence / conformité à vérifier |
| Ex. salle de bain | Modification plomberie | Type d'arrivée, évacuation, contraintes d'accès | Photos / métrés manquants |

## 3. Points à capter selon le métier
**Électricité** : tableau / compteur / disjoncteurs ; nombre et emplacement des prises ; éclairage / commandes / va-et-vient ; passages de câbles / saignées / gaines ; pièces humides et sécurité ; mise en conformité à vérifier.

**Plomberie** : arrivées / évacuations existantes ; type d'équipement à poser ou remplacer ; fuite / pression / accessibilité ; percements / passages / reprises ; matériel client ou fourni par l'artisan ; coupure d'eau et remise en service.

## 4. Photos et preuves terrain
| Photo | Ce qu'elle montre | Zone | Utilité pour le devis |
|---|---|---|---|

## 5. Base de pré-devis interne sans prix
| Poste probable à chiffrer | À prévoir | Données manquantes | Niveau de confiance |
|---|---|---|---|
| Ex. reprise prises salon | Dépose, fourniture, pose, vérification support | Nombre exact de prises | Moyen |
| Ex. remplacement chauffe-eau | Dépose ancien, fourniture, pose, raccordements | Volume / accès / évacuation | À confirmer |

## 6. Points bloquants avant devis
Métrés insuffisants · Nombre exact d'équipements inconnu · Zone non visitée · Références matériel absentes · Accès technique non vérifié · Norme ou conformité à contrôler · Choix client non arrêté · Coordination avec d'autres artisans nécessaire.

## 7. Sortie attendue
| Bloc | Contenu |
|---|---|
| Résumé dirigeant | 5 à 8 lignes sur le besoin, le contexte et la faisabilité à ce stade |
| Compte rendu structuré | Version claire des faits observés et des demandes client |
| Points à confirmer | Liste priorisée des informations manquantes avant devis |
| Base de pré-devis | Postes probables à chiffrer, sans prix inventé |
| Message client | Message court pour demander validation ou compléments |
